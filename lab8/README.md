# ЛР №8 — «Учёт расходов» (вариант 7)

Запуск: `mvn clean javafx:run` (JDK 17+, Maven) или откройте pom.xml в IntelliJ IDEA (Open as Project)
и запустите ExpenseApp.main.

Структура (папки вложенные, не "kz.atu.lab08" одним именем):
  src/main/java/module-info.java
  src/main/java/kz/atu/lab08/*.java
  src/main/resources/kz/atu/lab08/*.fxml

Пример данных: sample-expenses.csv (Файл -> Открыть).
