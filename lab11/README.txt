Лабораторная работа №11 — «Каталог студентов» (JavaFX, MVC)
Выполнил: Котов Расул, ИС 24-22

ОТКРЫТЬ В INTELLIJ IDEA
1. File > Open... и выберите файл pom.xml (или папку lab11) > Open as Project.
2. Дождитесь, пока Maven загрузит зависимости (нужен интернет, первый раз 1–2 минуты).
3. File > Project Structure > Project > SDK = JDK 21 (или новее).
4. Запуск: откройте kz.atu.lab11.Launcher и нажмите зелёный треугольник
   (или выберите конфигурацию "Launcher" справа вверху).
5. Тесты: ПКМ по src/test/java > Run 'All Tests'.

ЗАПУСК ИЗ КОНСОЛИ
  mvn test
  mvn javafx:run
